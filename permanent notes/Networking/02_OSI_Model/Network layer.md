# Network layer (L3)

Moves segments from one computer to another computer **on a different network**. **Routers live here.**

**Functions:**
- **Logical addressing**: [[IP Address]] on every packet
- **Routing**: picking the path to the destination
- **Load balancing**: spreading traffic across multiple paths

Hands the packet down to the [[Data Link layer]].
