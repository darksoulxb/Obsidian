# Application layer (L7)

The layer closest to the user. Implemented in **software**: browsers, mail clients, apps.

- Provides the network services apps actually call: [[HTTP]], [[Email Protocols|SMTP/POP3/IMAP]], [[DNS]], FTP, SSH.
- In [[TCP-IP Model|TCP/IP]] this layer also absorbs OSI's [[Presentation layer]] and [[Session layer]].
- Architecture: [[Client-Server and P2P]]
