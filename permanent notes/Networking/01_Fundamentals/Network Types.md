# Network Types

The internet is basically networks of networks, sorted by size.

| Type | Full name | Scope | Typical tech |
| --- | --- | --- | --- |
| **LAN** | Local Area Network | Home, office, campus | Ethernet, Wi-Fi |
| **MAN** | Metropolitan Area Network | A whole city | Fiber rings |
| **WAN** | Wide Area Network | Countries / continents | Optical fiber, leased lines, satellite |

## WAN technologies
1. **SONET** (Synchronous Optical Network): fiber-optic transport standard.
2. **Frame Relay**: older packet-switched WAN tech, mostly legacy now.
