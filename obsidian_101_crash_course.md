# Welcome to Your Obsidian Sandbox! 🚀

If you are reading this inside Obsidian, you are already doing it right. This note is designed to show you exactly how Markdown looks and feels. 

*Pro tip: Press `Ctrl` + `E` (or click the book/pen icon in the top right) to toggle between **Editing mode** (where you see the symbols) and **Reading mode** (where it looks clean).*

---

## 1. The Bread and Butter: Formatting
When taking notes during a fast-paced lecture, use these to make things stand out:

*   **Bold text** is created using double asterisks: `**like this**`. Use it for key terms.
*   *Italic text* is created using single asterisks: `*like this*`. Good for emphasis.
*   ==Highlighted text== is created using double equals signs: `==like this==`. (Great for exam review!).

## 2. Structuring Your Notes
Instead of massive walls of text, use headers to break things down. You just type a hashtag and a space.

# H1 (Biggest - Use for main note titles)
## H2 (Bigger - Use for main sections)
### H3 (Big - Use for sub-topics)

## 3. The Superpower: Linking 🕸️
This is why Obsidian beats standard folders. You can link ideas together effortlessly. 

*   **Internal Links:** Type two open brackets `[[` to link to another note. Try clicking this one -> [[My First Test Note]]. If the note doesn't exist yet, clicking the link will create it!
*   **External Links:** Wrap the text in brackets `[]` and the URL in parentheses `()`. Like this: [Obsidian Official Help](https://help.obsidian.md).

## 4. Stuff for CS and DevOps 💻
Since you are dealing with code, Markdown makes it incredibly easy to format it.

**Inline Code:** Use single backticks for small commands like `ping 8.8.8.8` or highlighting a variable like `int x = 5;`.

**Code Blocks:** Use triple backticks and type the language name to get syntax highlighting. 

```python
# A simple python script
def greet_student():
    print("Welcome to your new workflow!")
    
greet_student()
```

## 5. Staying Organized
You can quickly create task lists for your assignments:

- [ ] Watch lecture on networking layers
- [ ] Set up a new Docker container for testing
- [x] Learn how to use Obsidian

> **A Quick Quote / Callout:**
> You can use the greater-than sign `>` to create a blockquote. This is really useful if you want to visually separate a direct quote from a professor or a textbook from your own thoughts.
