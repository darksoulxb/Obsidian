# [[Traffic Speeds]]
 - Traffic speeds represent the frequency of data transfer
>Default measuring value is bits per second
   1 mbps = 1000000 bits/s
   1 gbps = 10^9

## [[Upload]]
- Upload refers to transmitting data from client to server 
## [[Download]]
- Download refers to receiving data from the server to client

# [[Traffic mediums ]]

#### [[Guided]]
- Internet traffic travels through set path via cable etc.
#### [[Unguided]]
-  mostly wireless changes frequently like [[WIFI]] and Bluetooth type shi

### [[Connection]] types:
- physical connections: optical cables, cordial cables.
- wireless: Bluetooth, WIFI, mobile networks etc.
